PeopleNest Setup Guide

Follow these steps to set up your HR Management System

1

Database Setup

Create a MySQL database and run the setup script:

1. Create database: CREATE DATABASE peoplenest_hrms;
2. Import: scripts/database-setup.sql
3. Update config/database.php with your credentials

Server Requirements

Make sure your server meets these requirements:

  • PHP 7.4 or higher
  • MySQL 5.7 or higher
  • PDO extension enabled
  • Web server (Apache/Nginx)

Security Configuration
